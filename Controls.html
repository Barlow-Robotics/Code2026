Robot Controls — Demo Configuration

One Xbox controller on Driver Station port 0. Drive speed is fixed at half.

ControlActionHow
Left stickDrive (field-relative)Half speed, fixed
Right stick XRotateHalf speed, fixed
Right triggerShootHold. Flywheel spins up, then the feeder, spindex and intake run.
Left triggerEjectHold. Feeder runs in eject mode with the spindex.
Right bumperIntake rollerHold to run, release to stop.
Left bumperReverseHold. Feeder and spindex run backwards.
YDeploy intake armPress
ARetract intake armPress
Menu (≡, button 8)Reset gyroPress
  • B, X, the D-pad and View are not used. The operator controller (port 1) is not used either.
  • Don't plug a controller into port 3. It's the testing controller, and its buttons 1 and 2 crash the robot code while vision is off.
  • Vision is off (HAS_VISION = False), so there is no turret auto-aim.
  • Bindings are defined in src/core/controller.py. Update this page when they change.
